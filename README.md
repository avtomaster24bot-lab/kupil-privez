# Купил — Привёз

https://avtomaster24bot-lab.github.io/kupil-privez/

Одностраничный лендинг и мастер заказа для одного перевозчика. Клиент нажимает крупные кнопки — и готовый текст уходит в WhatsApp **+7 702 718 4520**. Сервера, базы и аналитики нет. Состояние мастера живёт только в `sessionStorage`.

## Файлы
- `index.html` + `js/app.js` — главная, мастер заказа, установка, шаринг, QR.
- `card.html` — яркая визитка для скрина и рассылки.
- `privacy.html` — короткая политика.
- `js/config.js` — телефон и **примерные тарифы** (правьте здесь).
- `js/vendor/qrcode.js` — локальная библиотека QR, без CDN.
- `sw.js` — кэш `kupil-privez-vN`. Удаляет только свои кэши, кэши VEZU (`vezu-platform-*`, `vezu-static-*`) не трогает.

## Тарифы (по умолчанию, в ₸)
Формула: `минимум + max(0, км − включено) × ставка за км + грузчики × 4000`, округление до 500 ₸.

| Маршрут  | Минимум | Включено км | Далее, ₸/км |
|----------|---------|-------------|-------------|
| По городу | 5 000  | 5           | 250         |
| Пригород  | 10 000 | 10          | 300         |
| Межгород  | 15 000 | 0           | 200         |
| Грузчик   | 4 000 за человека |         |             |

Пример: по городу, 10 км, 2 грузчика → 5 000 + 5×250 + 2×4 000 = 14 250, на экране **14 500 ₸**. Это ориентир, не счёт.

При выкладывании новой версии увеличьте номер кэша в `sw.js`.
